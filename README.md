# 🌱 Agri-Tech

An AI-based agriculture project designed to support farmers with smart and technology-driven solutions.

## 🚀 Features

- 🌾 Crop disease detection
- 📊 Crop and agricultural data analysis
- 🤖 AI/ML-based solutions
- 🌱 Smart farming support
- 📈 Data-driven agricultural insights

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- AI/ML

## 🎯 Objective

The main objective of Agri-Tech is to use technology and artificial intelligence to help farmers make better decisions and improve agricultural productivity.
